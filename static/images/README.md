# Supplementary Results

This repository provides additional qualitative results for our submission.

`MAIN_DEMO.mp4` highlights the main results of our method.

We additionally provide qualitative comparisons on three datasets: CMU Panoptic, ETRI Baseball, and ETRI Break. For each sequence, we compare the FreeTimeGS (FTGS) baseline with our method.
